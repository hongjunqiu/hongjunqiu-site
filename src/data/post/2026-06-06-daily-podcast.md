**芊悦**：嗨大家好，欢迎收听《科技早知道》，我是芊悦～今天是6月6号，周六，天气挺好的，适合窝在沙发上聊点大新闻。

**萌萌**：我是萌萌！今天必须先剧透两条，第一，Anthropic 就是做 Claude 的那家公司，要上市了，估值六百亿美金！第二，Cloudflare 说互联网上机器人比人还多，然后被人写了篇文章狠狠打脸，标题直接就是 CEO 在撒谎，这个瓜我已经迫不及待要聊了。

**芊悦**：好好好别急，那咱们直接从最劲爆的开始。Anthropic 正式向美国证监会秘密递交了 IPO 申请，估值预计超过六百亿美金。这是整个 AI 赛道目前为止最重量级的一次上市动作，没有之一。

**萌萌**：六百亿！我的天哪，它们才成立五年，2021 年从 OpenAI 出来的。五年做到六百亿估值，比当年 Facebook 上市前的增速还快吧？而且它们选择了保密递交这种方式，是什么操作？

**芊悦**：保密递交就是先把上市材料交给证监会审核，但暂时不向公众公开招股书的内容。等审核差不多了、确认市场时机合适了再正式公开。好处就是进可攻退可守，如果发现市场环境不对劲，还有机会悄悄撤回，不会太丢面子。

**萌萌**：就像先偷偷投简历试水温，不行就当没投过，聪明聪明。但我有个很核心的担心——Anthropic 一直标榜自己是安全优先的 AI 公司，这是它们最最核心的品牌标签和差异化定位。上市之后华尔街那帮人天天盯着季度财报要增长，这个安全的调性还能保持住吗？

**芊悦**：你这个问题问到了关键。我觉得短期内它们百分之百还会继续猛打安全牌，因为这就是差异化卖点，也是机构客户选择 Claude 的核心原因。但长期来看，股东压力是非常真实的存在。到时候做最安全的 AI 和做最赚钱的 AI 如果产生了冲突怎么办？这个是留给创始人 Dario Amodei 的终极难题。

**萌萌**：我倒觉得这两者不一定是矛盾的。你看 OpenAI 从非营利转营利，当时争议那么大，结果照样活得好好的，产品越来越强，估值越来越高。市场最终看的是产品力和收入增长曲线，安全叙事更多是品牌层面的包装，不是商业模式本身的约束。

**芊悦**：话是这么说啦但是我真心觉得 Anthropic 的安全不只是叙事包装，而是贯穿整个技术路线的核心方法论。Claude 的宪法 AI 对齐方法，在业内公认做得比竞品好一个档次。很多金融机构和政府客户选 Claude 就是看中了它的合规性和安全性。如果为了追增长把这个根基丢了，反而可能流失最忠实的那批高价值付费用户。

**萌萌**：有道理，安全本身就是它的商业护城河。而且你知道吗，它们上市前还搞了个大动作，开源了一个 AI 安全漏洞发现框架，名字超长叫 defending code reference harness，包含威胁建模、自动扫描、漏洞分类和自动修补这一整套能力。上市前这个时间点搞开源，明显是在向技术社区表态。

**芊悦**：一边递交 IPO 一边做开源，这组合拳打得确实聪明。既稳住了开发者社区的口碑和信任，又给投资人讲了个技术领先加生态开放的好故事。好，说到 GitHub 上的开源项目——

**萌萌**：哎说到这个！GitHub Trending 上今天有个项目特别酷，叫 hermes agent，Nous Research 做的。号称是目前唯一一个具备内建学习循环能力的 AI Agent，意思是这个 Agent 能从自己的执行经验中创建新技能，然后持续改进自己的工作方式。

**芊悦**：对这个概念挺有意思。你可以这样理解，普通的 Agent 每次执行任务基本都是从零开始，顶多带点上下文记忆。但 hermes agent 不一样，它每做完一件事就会把成功经验总结打包成一个结构化的技能模块存起来，下次遇到类似任务可以直接调用这个技能。就好比你学骑自行车，摔了几次之后大脑形成了永久的肌肉记忆，以后就再也不用重新学了。

**萌萌**：所以不是真的在自我进化，更像是在积累可复用的经验包？那它跟我们平时用的带记忆功能的 Agent 到底有什么本质区别呢？

**芊悦**：核心区别在于存储内容的性质。记忆型 Agent 存的是文本信息，本质是参考资料，需要重新理解和执行。而 hermes agent 存的是可直接执行的技能模块，是封装好的逻辑代码。一个是原材料一个是成品。

**萌萌**：我懂了！一个是写日记，一个是考驾照。日记你翻翻看看就算了，驾照可是真能上路开车的。好好好咱们聊今天另一个大瓜，Cloudflare 数据被质疑的事。

**芊悦**：对。Cloudflare 之前发了份报告说互联网上的 Bot 流量已经占到了 57.4%，正式超过了人类流量。然后 Hacker News 上出了一篇分析文章，标题直接就是 Cloudflare CEO 在骗你，特别刚。

**萌萌**：这标题也太猛了吧哈哈哈。它主要质疑什么？

**芊悦**：主要质疑统计口径。首先 Cloudflare 作为 CDN 和安全服务商，它看到的流量样本本身就不能代表整个互联网。其次它把搜索引擎爬虫、正常的 API 调用、健康检查探针这些全部归类为 Bot，那数字当然高得吓人。本质上是在混淆自动化流量和恶意机器人流量这两个完全不同的概念。

**萌萌**：但从技术定义来说，搜索引擎爬虫确实是自动化程序在跑啊，它本来就不是人在操作的，算 Bot 也没毛病吧？

**芊悦**：技术上没毛病，但 Cloudflare 发这个报告的潜台词是恶意 Bot 泛滥互联网很危险，言下之意就是快来买我们的安全防护服务吧。这就有点恐惧营销的味道了，就像卖保险的天天跟你说出门可能被车撞一样。

**萌萌**：哈哈这比喻太损了。不过我不完全同意你说的恐惧营销。Cloudflare 作为全球最大的网络基础设施之一，每天经手几十亿请求，它的数据样本量确实足够大有统计意义。就算口径有偏差，趋势性结论应该还是相当可信的。而且你去看 Reddit 上的讨论，很多一线开发者都在分享说自己服务器的异常 Bot 请求这半年暴增了好几倍。

**芊悦**：好吧你说的有道理，特别是 AI 爬虫确实越来越猖獗了。那我折中一下吧，Bot 流量快速增长的大趋势是真实可信的，但 57.4% 这个精确数字嘛，大家听个乐就行，打个七折更接近真相。

**萌萌**：行这个观点我买单。

**芊悦**：对了说到搜索和 AI 的关系，DuckDuckGo 做了件特别有趣的逆操作。它推出了一个无 AI 搜索的浏览器扩展，就是帮你屏蔽掉搜索结果中所有 AI 生成内容的。结果安装量直接暴涨了 30%。

**萌萌**：都 2026 年了还有这么多人主动选择拒绝 AI 帮助？这是什么返璞归真运动吗？

**芊悦**：还真挺多人受不了 Google 那个 AI Overview 的。每次搜一个简单问题，上面先甩一大段 AI 生成的内容把真正有用的网页结果挤到下面去，关键那段 AI 内容有时候还是不准确的。用户就想要十条干净的蓝色链接自己判断取舍，这个要求很过分吗？

**萌萌**：确实不过分。不是所有场景都需要 AI 来帮你总结和咀嚼，有时候用户就是想要原始信息源让自己做判断。这波 DuckDuckGo 属于逆潮流操作但精准踩中了一部分用户的真实痛点。

**芊悦**：接下来快速过几条。微软 Build 2026 大会上一口气发了三个重磅产品，Project Solara 是新的编码助手，Scout 是专门做网页操作的 AI Agent，还有跟 Nvidia 合作推出了 RTX Spark 芯片。微软全面转向 Agent 优先的计算范式了。

**萌萌**：Nvidia 那边更疯狂，RTX Spark 是专门给个人电脑用的 AI 芯片，还直接跟微软联手搞了个 Surface Laptop Ultra 笔记本。这是正式向 Apple Silicon 和 Qualcomm 宣战了，PC 芯片市场的三国杀终于开打！

**芊悦**：还有个实用的开源工具推荐，GitHub 上一个 token 压缩库叫 headroom，号称能帮开发者节省 60 到 95% 的 token 消耗。原理是在数据送到大模型之前先把工具输出日志和 RAG 分块这些冗余度高的内容做智能压缩。

**萌萌**：对开发者来说省 token 就是省钱，这个太实用了。太空那边也有新闻，国际空间站空气泄漏宇航员被要求返回安全区域避难。这个站修修补补真的太老了，2030 年就该退役了。

**芊悦**：最后提一个前沿论文，NVIDIA 发了 Cosmos 3 全模态世界模型，能同时处理和生成语言图像视频音频和动作序列，专门为物理 AI 设计的。未来机器人和自动驾驶都需要这种理解真实物理世界的能力。

**萌萌**：物理 AI 这个赛道越来越火了，从特斯拉的人形机器人到各种无人配送车，感觉明年就能看到不少真正落地的商业化应用了。世界模型就是这些物理智能体的大脑核心。

**芊悦**：好今天总结两个关键洞察。第一个趋势是 AI 公司正式进入了资本收割期，Anthropic 的六百亿美金 IPO 是一个非常标志性的里程碑事件，意味着这个行业从烧钱阶段进入了兑现阶段。第二个趋势是反 AI 需求正在形成一个真实的细分市场，DuckDuckGo 的逆势增长告诉我们，在这个 AI 无处不在的时代，简单纯粹和用户自主权永远有人愿意为之买单。科技不该只有一个方向。

**萌萌**：每天 5 分钟，掌握科技圈大小事。我们明天见～
